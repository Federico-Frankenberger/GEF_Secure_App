# Fuentes

Material histórico de insumo/planificación (análisis estratégico inicial, specs previas
a implementar, marco de referencia de industria sobre tracking de remediación), de fechas
tempranas del proyecto (fin de julio–20/08/2026), **anterior** a la documentación viva
actual.

**Esto no es la fuente de verdad vigente.** Para el estado real e implementado del
proyecto, ver [`docs/README.md`](../README.md) y [`knowledge-base/`](../../knowledge-base/README.md).
Estos documentos se conservan por su valor histórico (entender de dónde vino cada
decisión, y qué se decidió no implementar) — pueden contradecir lo que existe hoy, y en
ese caso el código y la documentación viva son la referencia correcta, no este material.
